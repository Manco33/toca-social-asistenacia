# **App Name**: ClockWise Tracker

## Core Features:

- User Authentication: Secure login page to authenticate users (administrators, technicians).
- Technician Time Tracking: Technicians can record timestamps for arrival at office, departure from office, arrival at project, lunch, departure from project, return to office, and departure for the day, logging hours and geolocation.
- Geolocation Tracking: Capture geolocation data for each time entry made by technicians to verify location.
- Automatic Calculation of Regular Hours: Based on timestamps, calculates number of normal work hours performed by technicians
- Overtime Calculation and Management: Automatic calculation of overtime hours based on marked time, saving and summing of extra hours for payroll.
- Dashboard Views: Dedicated dashboards for admins (overview of all technician activity) and technicians (personal hour tracking).

## Style Guidelines:

- Primary color: Teal (#008080) to evoke feelings of reliability.
- Background color: Very light greenish-blue (#F0FFFF).
- Accent color: A vibrant yellow-green (#ADFF2F) to add visibility to calls to action.
- Body and headline font: 'PT Sans', a humanist sans-serif, to bring warmth and readability.
- Simple and clear icons for time tracking actions (clock, location, user).
- Clean and responsive layout optimized for quick time entries.
- Subtle animations for successful time entry submissions.
