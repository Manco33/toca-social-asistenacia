Fase 1: Enrolamiento (Registro del Descriptor)

Captura tu descriptor facial: un vector de 128 números que te identifica de forma única.

¿Qué sucede?
- Se capturan 3 muestras de tu cara
- Se extrae un descriptor (128 números) de cada muestra
- Se promedian los 3 descriptores para mayor precisión
- El resultado se almacena para futuras comparaciones

Código: Múltiples Muestras (Mejor Precisión)

// Capturar 3 muestras y promediarlas async function enrollMultipleSamples() { const descriptors = []; for (let i = 0; i < 3; i++) { // Esperar 0.5 segundos entre muestras await new Promise(resolve => setTimeout(resolve, 500)); const detection = await faceapi .detectSingleFace(videoElement, DETECTION_OPTIONS) .withFaceLandmarks() .withFaceDescriptor(); descriptors.push(Array.from(detection.descriptor)); } // Promediar los 3 descriptores const averaged = descriptors[0].map((_, i) => descriptors.reduce((sum, desc) => sum + desc[i], 0) / 3 ); return averaged; }

Fase 2: Verificación Facial (Login)

Compara tu cara actual con el descriptor almacenado usando distancia euclidiana.

¿Cómo funciona la comparación?
- Se captura un nuevo descriptor en vivo
- Se calcula la distancia euclidiana entre descriptores
- Distancia < 0.6 = ¡Coincidencia! (autenticado)
- Distancia ≥ 0.6 = No coincide (rechazado)

Código: Comparación de Descriptores

// Función: Distancia Euclidiana function euclideanDistance(a, b) { if (a.length !== b.length) { throw new Error('Vectores deben tener igual longitud'); } let sum = 0; for (let i = 0; i < a.length; i++) { const diff = a[i] - b[i]; sum += diff * diff; // Sumar cuadrados de diferencias } return Math.sqrt(sum); // Raíz cuadrada = distancia euclidiana } // Ejemplo: const distance = euclideanDistance(liveDescriptor, storedDescriptor); const isMatch = distance < 0.6; // Umbral de decisión console.log(`Distancia: ${distance.toFixed(4)}`); console.log(`¿Coincide? ${isMatch ? 'SÍ' : 'NO'}`); console.log(`Confianza: ${((1 - distance) * 100).toFixed(1)}%`);

Fase 3: Detección de Vida (Anti-Spoofing)

Previene ataques con fotos o videos pidiendo un desafío (parpadeo o movimiento).

⚠️ Seguridad: Sin detección de vida, alguien podría usar una foto tuya para autenticarse. Esta prueba fuerza un desafío para verificar que es una cara real.
Desafíos disponibles:
- Parpadeo: Detecta el cierre/apertura de ojos (3 segundos, mín. 2 parpadeos)
- Movimiento de cabeza: Detecta rotación de cabeza (5 segundos, mín. 15°)

Código: Detectar Parpadeo (EAR - Eye Aspect Ratio)

// Eye Aspect Ratio: Medida para detectar parpadeos function calculateEyeAspectRatio(eye) { // eye es un array de 6 puntos (landmarks de ojo) const distance = (p1, p2) => { return Math.sqrt((p1.x - p2.x)**2 + (p1.y - p2.y)**2); }; // EAR = (||p2-p6|| + ||p3-p5||) / (2 * ||p1-p4||) const a = distance(eye[1], eye[5]); const b = distance(eye[2], eye[4]); const c = distance(eye[0], eye[3]); return (a + b) / (2 * c); } // Loop de detección async function detectBlink(durationSeconds = 3) { const endTime = Date.now() + durationSeconds * 1000; let blinkCount = 0; let eyeClosureFrames = 0; const BLINK_THRESHOLD = 0.2; // EAR bajo = ojos cerrados while (Date.now() < endTime) { const detection = await faceapi .detectSingleFace(videoElement, DETECTION_OPTIONS) .withFaceLandmarks(); const leftEye = detection.landmarks.getLeftEye(); const rightEye = detection.landmarks.getRightEye(); const leftEAR = calculateEyeAspectRatio(leftEye); const rightEAR = calculateEyeAspectRatio(rightEye); const avgEAR = (leftEAR + rightEAR) / 2; if (avgEAR < BLINK_THRESHOLD) { eyeClosureFrames++; } else { if (eyeClosureFrames > 3) blinkCount++; // Se confirma parpadeo eyeClosureFrames = 0; } await new Promise(r => setTimeout(r, 30)); } return blinkCount >= 2; // Requiere mín. 2 parpadeos }

Código: Detectar Movimiento de Cabeza

// Calcula ángulo de cabeza usando landmarks function calculateHeadAngle(landmarks) { // landmarks[30] = nariz // landmarks[36] = ojo izquierdo // landmarks[45] = ojo derecho const nose = landmarks[30]; const leftEye = landmarks[36]; const rightEye = landmarks[45]; const eyeDx = rightEye.x - leftEye.x; const eyeDy = rightEye.y - leftEye.y; return Math.atan2(eyeDy, eyeDx) * (180 / Math.PI); // Convertir a grados } // Detectar giro de cabeza async function detectHeadTurn(durationSeconds = 5) { const endTime = Date.now() + durationSeconds * 1000; const headAngles = []; while (Date.now() < endTime) { const detection = await faceapi .detectSingleFace(videoElement, DETECTION_OPTIONS) .withFaceLandmarks(); const angle = calculateHeadAngle(detection.landmarks.positions); headAngles.push(angle); await new Promise(r => setTimeout(r, 50)); } const minAngle = Math.min(...headAngles); const maxAngle = Math.max(...headAngles); const difference = Math.abs(maxAngle - minAngle); return difference > 15; // Requiere mín. 15° de diferencia }

Consideraciones de Seguridad

✓ VENTAJAS: - Client-side: No envías imágenes a servidores - Bajo costo: Sin APIs de pago - Rápido: Modelos optimizados (TinyFaceDetector) - Flexible: Puedes ajustar umbrales (0.6 es base) ✗ LIMITACIONES: - Spoofing: Sin detección de vida = vulnerable a fotos - Luz: Requiere buena iluminación - Ángulo: Funciona mejor cara frontal - Precisión: ~95-98% en condiciones ideales RECOMENDACIONES: ✓ Implementar SIEMPRE Fase 3 (Liveness) ✓ Usar múltiples muestras en registro (3+) ✓ Permitir reintentos (máximo 3-5) ✓ Requerir acceso a cámara ✓ Guardar descriptor HASHEADO en BD ✓ Implementar rate limiting
