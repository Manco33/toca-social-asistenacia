                    POSTGRESQL - CÓDIGO PARA EJECUTAR
═══════════════════════════════════════════════════════════════════════════════

Tu BD usa PostgreSQL (Supabase), aquí está el código correcto.


📋 TABLA 1: EMPLEADOS
═══════════════════════════════════════════════════════════════════════════════

OBJETIVO: 
  ✅ Agregar columna DPI (hasta 13 cifras, editable)
  ✅ Agregar columna celular
  ✅ El ID se mantiene intacto (no se edita)
  ✅ DPI apunta al empleado (UNIQUE)


CÓDIGO POSTGRESQL:

```sql
-- Agregar columnas DPI (hasta 13 cifras) y celular a empleados
ALTER TABLE empleados
ADD COLUMN IF NOT EXISTS dpi VARCHAR(13) UNIQUE NOT NULL DEFAULT '',
ADD COLUMN IF NOT EXISTS numero_celular VARCHAR(20);

-- Crear índice en DPI para búsquedas rápidas
CREATE INDEX IF NOT EXISTS idx_empleados_dpi ON empleados(dpi);

-- Crear restricción para validar que DPI sea solo números (máximo 13 cifras)
ALTER TABLE empleados
ADD CONSTRAINT check_dpi_format CHECK (dpi = '' OR (dpi ~ '^[0-9]{1,13}$'));
```

¿QUÉ HACE?
  • dpi: Campo unique de máximo 13 cifras (solo números)
  • numero_celular: Campo para teléfono (puede ser NULL)
  • ID: Se mantiene igual (no se toca)
  • DPI: Es el identificador editable que apunta al empleado


CÓMO USAR DESPUÉS:

```sql
-- Actualizar empleado con DPI y celular
UPDATE empleados
SET 
  dpi = '1234567890123',
  numero_celular = '+502 7123 4567'
WHERE id = 1;

-- Buscar empleado por DPI
SELECT id, nombre, usuario, dpi, numero_celular
FROM empleados
WHERE dpi = '1234567890123';

-- Editar el DPI (cambiar a uno diferente)
UPDATE empleados
SET dpi = '9876543210987'
WHERE id = 1;

-- Ver empleados con DPI
SELECT id, nombre, usuario, dpi, numero_celular
FROM empleados
WHERE dpi != ''
ORDER BY id;
```


📋 TABLA 2: PROYECTOS
═══════════════════════════════════════════════════════════════════════════════

OBJETIVO:
  ✅ Hacer el ID editable


CÓDIGO POSTGRESQL:

```sql
-- Hacer el ID editable: eliminar auto-increment
ALTER TABLE proyectos ALTER COLUMN id DROP DEFAULT;
```


CÓMO USAR DESPUÉS:

```sql
-- Editar el ID de un proyecto
UPDATE proyectos
SET id = 1001
WHERE id = 16;

-- Crear proyecto con ID específico
INSERT INTO proyectos (id, nombre, ubicacion_del_proyecto, soluciones, horas_totales)
VALUES (2001, 'Mi Proyecto', 'Ubicación', 'Contacto', 100);

-- Ver proyectos
SELECT id, nombre, ubicacion_del_proyecto, horas_totales
FROM proyectos
LIMIT 10;
```

🔍 SI ALGO FALLA:
═══════════════════════════════════════════════════════════════════════════════

Error: "column already exists"
  → Las columnas ya existen. Eso está bien, el código usa IF NOT EXISTS.

Error: "duplicate key value"
  → Hay dos empleados con el mismo DPI. Verifica los datos.

Error: "cannot drop default"
  → El ID no tiene auto-increment. Ignora ese comando.

Error: "constraint violation"
  → El DPI tiene más de 13 cifras o caracteres no numéricos. Valida.
